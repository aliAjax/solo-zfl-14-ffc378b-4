# 家庭维修事项

端口规划：`5114`

```bash
npm install
npm run dev
```

第一版闭环：记录维修问题、按状态查看、更新处理状态、统计未完成预计费用，支持照片链接并使用localStorage保存数据。

第二版：列表上方新增搜索框（按位置、问题描述、备注过滤）和排序控件（按优先级、预计费用、创建时间排序，方向可切换），搜索词与排序设置随localStorage一并保存。工具栏提供「清空已完成」批量操作和「导出 JSON」下载（文件名带日期，只读不写本地存储）；照片加载失败时显示占位文字。统计区分别展示未完成预计费用和已完成支出。

```bash
npm test        # 浏览器回归测试（Playwright）
npm run build   # 生产构建
```
